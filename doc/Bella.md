## 一、总体介绍

### 1.1 角色定位

贝拉的核心玩法围绕「阴阳」属性展开：卡组的阴阳构成决定白拉/黑拉状态，状态再按阴阳差值修正对应属性的卡牌。整体定位：**卡组即人格**——通过构筑决定战斗倾向（白拉·守护 / 黑拉·激进），配合「心之壁」经济与充能球系统形成多流派（纯阳、纯阴、太极混搭、混沌反打）。

### 1.2 核心机制：阴阳

#### 1.2.1 基本规则

- 每张贝拉卡牌带有「阳」或「阴」标签。
- **颜色对应**：白拉 = 阳（白），黑拉 = 阴（黑）。
- **攻防独立**：卡牌的阴阳属性与它偏攻击还是偏防守**互相独立**，不绑定。阴阳只看"卡牌属性"本身。
- 状态判定：统计贝拉当前拥有的**全部卡牌**。
  - 阳牌数 > 阴牌数 → **白拉**
  - 阴牌数 > 阳牌数 → **黑拉**
  - 相等 → **白拉**
- 状态随卡组变动（抓牌、删牌、转化等）自动更新。
- **中立牌**：灵魂、诅咒、战斗中生成的临时牌等无标签，不参与计数、不受状态影响。

#### 1.2.2 状态对卡牌的影响

| 卡牌属性 | 白拉状态 | 黑拉状态 |
|----------|----------|----------|
| 阳 | 加成 | 削弱 |
| 阴 | 削弱 | 加成 |

- **差值制**：加成/削弱幅度不是固定值，而是随差值 `d = |阳牌数 − 阴牌数|` 缩放。例如某牌效果值修正为 `±(d ÷ 3)`（d 每 3 张差 ±1）：相符牌加成、相反牌削弱。
- **无上限**：d 越大修正越强，鼓励极限偏科构筑（数值平衡由测试把控）。
- **保底**：削弱后效果至少保留 1 点，避免异属性牌完全失效。
- **相等**：d = 0 时状态判白拉，但无任何修正。
- **设计原则**：阴阳与心之壁/充能球系统整体**正交**，不强制绑定；但设计具体卡牌时允许产生联系。

**各卡牌参与修正的数值（已定稿）**：

#### 1.2.3 扩充子系统（规划中，后续卡牌设计参考）

> **本轮开发范围**：仅实现静态阴阳框架（卡牌标签 + 差值修正 + 遗物双面加成），以下全部子系统暂缓。

**① 战斗内动态**
- 切换牌「阴阳逆转」：打出后状态翻转（本场战斗内持续）。
- 临时状态牌「趋光 / 堕影」：本回合内视为白拉/黑拉。
- 立场能力牌「立场宣言」（稀有）：本场战斗内将状态固定为所选一方，不受卡组计数影响。
- 双极牌「太极劲」：同时算阴阳、永远相符。

**② 卡牌构筑深度**
- 转化牌「拨乱反正」：消耗，将一张手牌/牌组牌的属性翻转。
- 反其道牌「混沌之心」：在**相反**状态下获得额外效果，奖励混组。
- 升级翻转属性：少数牌升级后阴阳翻转，使升级成为构筑决策。

**③ 战斗外联动**
- 事件「阴阳师」：按当前状态提供不同选项与奖励。
- 药水「阴阳灵液」：白拉/黑拉时饮用效果不同。
- 纪元解锁：纪元 1 开放双极牌，纪元 2 开放切换牌，纪元 3 开放转化工具。

#### 1.2.4 落地要求

- **UI 标注**：卡牌奖励与牌组界面需显式显示阴阳标签，否则玩家无法决策。
- **状态展示**：战斗内由可见状态 Power（`BaiLaPower` / `HeiLaPower`）挂在角色下方（战斗开始时按当前状态施加）；战斗外由初始遗物 hover tip 动态显示当前状态（`AdditionalHoverTips` 每次悬停重算）。
- **初始卡组配比**：10 张起始牌配成 5 阳 5 阴（开局白拉、可自由转向）。
- **待定事项**：状态名「黑拉」与已有稀有能力牌「黑拉」（`EvilBella`）重名，命名冲突后续统一处理。
- **纪元系统**：贝拉 `RequiresEpochAndTimeline = false`，不启用纪元/时间线，见文末「五、纪元系统」。
