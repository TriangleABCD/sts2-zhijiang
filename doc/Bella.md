# 枝江 mod - 角色 - 贝拉

> 设计文档，随开发进度持续更新。

---

## 一、总体介绍

### 1.1 角色定位

贝拉的核心玩法围绕「阴阳」属性展开：卡组的阴阳构成决定白拉/黑拉状态，状态通过初始遗物「贝极星」带来馈赠与代价（白拉·技能格挡 / 黑拉·随机攻击，并以力量/敏捷为代价），由属性系统自动作用于卡牌。整体定位：**卡组即人格**——通过构筑决定战斗倾向（白拉·守护 / 黑拉·激进），配合「心之壁」经济与充能球系统形成多流派（纯阳、纯阴、太极混搭、混沌反打）。

### 1.2 核心机制：阴阳

#### 1.2.1 基本规则

- 每张贝拉卡牌带有「阳」或「阴」标签。
- **颜色对应**：白拉 = 阳（白），黑拉 = 阴（黑）。
- **攻防独立**：卡牌的阴阳属性与它偏攻击还是偏防守**互相独立**，不绑定。阴阳只看"卡牌属性"本身。
- 状态判定：统计贝拉当前拥有的**全部卡牌**。
  - 阳牌数 > 阴牌数 → **白拉**
  - 阴牌数 > 阳牌数 → **黑拉**
  - 相等 → **白拉**
  - 战斗中：消耗掉的牌与打出后的能力牌不再参与计数（能力牌打出后停留在打出堆、本场战斗不再回到循环），状态随牌堆变动实时更新。
- 状态随卡组变动（抓牌、删牌、转化等）自动更新。
- **中立牌**：灵魂、诅咒、战斗中生成的临时牌等无标签，不参与计数、不受状态影响（「了转反」也是无标签的中立牌）。**例外**：本 mod 状态牌「牛批」带阴标签，参与阴阳计数，可在局内通过加入/移除「牛批」改变黑白拉状态。
- **反差牌**：与当前状态阴阳相反的牌（白拉时的阴牌、黑拉时的阳牌），无标签牌恒不是反差牌。部分卡牌（如「情人越多越气派」）按本回合此前打出的反差牌数量结算（打出瞬间按当时状态判定，Replay 类多段重复打出只算一张）。

#### 1.2.2 状态效果：贝极星的馈赠与代价（2026-08-15 定稿）

阴阳不再逐张修正卡牌数值，而是由初始遗物「贝极星」提供全局效果，通过力量/敏捷等属性系统自动作用于卡牌：

| 状态 | 馈赠（buff） | 代价（debuff） |
|------|------|------|
| 白拉（阳 ≥ 阴） | 每打出 1 张技能牌，获得 `1 + d ÷ 3` 点格挡 | 战斗开始时失去 `1 + d ÷ 3` 点力量（整场战斗） |
| 黑拉（阴 > 阳） | 每打出 1 张攻击牌，对随机一名敌人造成 `1 + d ÷ 3` 点伤害 | 战斗开始时失去 `1 + d ÷ 3` 点敏捷（整场战斗） |

- **差值制**：`d = |阳牌数 − 阴牌数|`，馈赠/代价均为 `1 + d ÷ 3`（基数 1，d 每 3 张差 ±1）。
- **无上限**：d 越大效果越强，鼓励极限偏科构筑（数值平衡由测试把控）。
- **相等**：d = 0 时状态判白拉，馈赠/代价均为基数 1。
- **实时性**：馈赠在每次出牌时按当前 d 实时计算；代价在战斗开始时按当时状态施加，战斗中状态翻转时动态切换（撤销旧代价、施加新代价）。任何改变阴阳计数的牌堆变动（消耗、打出能力牌、生成牌等）都会触发状态重算与图标替换。
- **固定值**：白拉格挡不受敏捷修正；黑拉伤害不受力量修正、不触发攻击反击。代价通过压低相反侧的卡牌实现"自动控制"（白拉压攻击牌、黑拉压防御牌）。
- **代价展示**：直接施加原版力量/敏捷能力的负层数，角色下方带图标可见。
- **闪耀贝极星**：馈赠与贝极星数值完全一致，但**只有馈赠、没有代价**。
- **设计原则**：阴阳与心之壁/充能球系统整体**正交**，不强制绑定；但设计具体卡牌时允许产生联系。

> 代码实现：馈赠为 `BellarisBlockPower`（白拉技能格挡）与 `BellarisHeiLaAttackPower`（黑拉随机攻击），两遗物共用、出牌时实时判状态；代价由 `BellarisYinYangDebuffPower` 控制（仅贝极星施加），`BellaYinYangService.RegisterCombatStateSync()` 订阅 `CombatStartingEvent` / `CardMovedBetweenPilesEvent` 同步状态标记与代价。旧版逐卡修正（`IBellaYinYangCorrectionCard` + `BellaYinYangCorrectionPower`）已废除。

#### 1.2.3 扩充子系统（规划中，后续卡牌设计参考）

> **本轮开发范围**：仅实现静态阴阳框架（卡牌标签 + 状态判定 + 贝极星馈赠与代价），以下全部子系统暂缓。

**① 战斗内动态**
- 切换牌「阴阳逆转」：✅ 已实现——「了转反」（稀有技能牌，消耗；本场战斗内黑白拉判定翻转，升级移除消耗；实现为隐藏 Power 标记 + `IsBaiLa/IsHeiLa` 取反）。
- 临时状态牌「趋光 / 堕影」：本回合内视为白拉/黑拉。
- 立场能力牌「立场宣言」（稀有）：本场战斗内将状态固定为所选一方，不受卡组计数影响。
- 双极牌「太极劲」：同时算阴阳、永远相符。

**② 卡牌构筑深度**
- 转化牌「拨乱反正」：消耗，将一张手牌/牌组牌的属性翻转。
- 反其道牌「混沌之心」：在**相反**状态下获得额外效果，奖励混组。
- 升级翻转属性：少数牌升级后阴阳翻转，使升级成为构筑决策。

**③ 战斗外联动**
- 事件「阴阳师」：按当前状态提供不同选项与奖励。
- 药水「阴阳灵液」：白拉/黑拉时饮用效果不同。
- 纪元解锁：纪元 1 开放双极牌，纪元 2 开放切换牌，纪元 3 开放转化工具。

#### 1.2.4 落地要求

- **UI 标注**：卡牌奖励与牌组界面需显式显示阴阳标签，否则玩家无法决策。
- **数量角标**：初始遗物「贝极星」（及升级版「闪耀贝极星」）图标左下角显示当前阳牌数、右下角显示当前阴牌数；战斗外读卡组、战斗内随牌堆变动实时刷新，口径与状态判断一致。
- **手牌泛光**：战斗中手牌与当前状态同向的牌（白拉=阳牌、黑拉=阴牌）泛金色光，反差牌（白拉=阴牌、黑拉=阳牌）泛红色光；使用 RitsuLib ModCardHandOutlineRegistry 逐帧刷新（BellaHandGlow.Register()），状态翻转时自动变色，中立牌不发光。
- **状态展示**：战斗内由可见状态 Power（`BaiLaPower` / `HeiLaPower`）挂在角色下方（战斗开始时按当前状态施加，状态翻转时动态替换）；战斗外由初始遗物 hover tip 动态显示当前状态（`AdditionalHoverTips` 每次悬停重算）。
- **初始卡组配比**：10 张起始牌配成 5 阳 5 阴（开局白拉、可自由转向）。
- ~~状态名「黑拉」与已有稀有能力牌「黑拉」（`EvilBella`）重名~~：已解决（2026-08-15），卡牌更名为「黑贝拉sama」（代码文件名不变）。
- **纪元系统**：贝拉 `RequiresEpochAndTimeline = false`，不启用纪元/时间线，见文末「五、纪元系统」。
