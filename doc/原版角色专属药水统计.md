## 一、概念与总体结论

### 1.1 什么是"角色专属药水"

每个可玩角色拥有一个专属药水池（`{角色}PotionPool`），池中的药水**不会**出现在共享药水池（`SharedPotionPool`）中，因此属于该角色独有内容。

| 角色 | 池文件 | 池内药水数 | 解锁纪元 |
|------|--------|-----------|----------|
| 铁甲战士 Ironclad | `IroncladPotionPool` | 3 | `Ironclad4Epoch` |
| 静默猎人 Silent | `SilentPotionPool` | 3 | `Silent4Epoch` |
| 机器人 Defect | `DefectPotionPool` | 3 | `Defect4Epoch` |
| 死灵法师 Necrobinder | `NecrobinderPotionPool` | 3 | `Necrobinder4Epoch` |
| 君王 Regent | `RegentPotionPool` | 3 | `Regent4Epoch` |
| **合计** | — | **15（无重复）** | 5 |

> 五个角色池互不重叠，且与共享池零重复：15 瓶专属药水均为唯一 ID。

### 1.2 稀有度构成：完全统一的"3 瓶套"模板

| 稀有度 | 每角色数量 | 全游戏专属药水数 |
|--------|-----------|------------------|
| Common（普通） | 1 | 5 |
| Uncommon（罕见） | 1 | 5 |
| Rare（稀有） | 1 | 5 |
| **合计** | **3** | **15** |

> `PotionRarity` 只有 `None / Common / Uncommon / Rare / Event / Token` 六档，**没有 Starter**；且原版 5 个角色均未覆写 `CharacterModel.StartingPotions`（默认空数组），因此没有开局携带的专属药水。

### 1.3 解锁规律：一次性解锁 3 瓶

- 每个角色池通过 `{角色}4Epoch` 同时解锁全部 3 瓶药水；`GetUnlockedPotions` 在纪元未揭示时返回空数组，揭示后一次性放行。
- 共享池另有 `Potion1Epoch`、`Potion2Epoch` 各锁 3 瓶（甲虫汁 / 马萨雷斯的赠礼 / 预知之滴；消亡粉末 / 瓶中船 / 癫狂之触）。这 6 瓶不是"专属药水"，只是被时间线锁住的共享药水。
- 游戏进度统计口径（`SaveManager.GetPotionUnlockEpochIds`）：共 7 个药水解锁纪元 × 3 = **21 瓶可解锁药水**（15 专属 + 6 共享）。

### 1.4 使用场景与目标

| 维度 | 分布 | 说明 |
|------|------|------|
| `PotionUsage.AnyTime` | 1 瓶 | 仅 `BloodPotion`（可脱战使用，可对任意玩家） |
| `PotionUsage.CombatOnly` | 14 瓶 | 其余全部仅战斗内使用 |
| 目标：任意玩家 | 4 瓶 | BloodPotion、SoldiersStew、GhostInAJar、KingsCourage |
| 目标：自身 | 9 瓶 | 大多为资源/状态型 |
| 目标：任意敌人 | 2 瓶 | PoisonPotion、PotionOfDoom |

### 1.5 设计主题

角色专属药水全部是角色核心机制的"浓缩版"：

| 角色 | 核心主题 | 专属药水关键词 |
|------|----------|----------------|
| Ironclad | 自愈 / 打击 / 消耗 | 回复、重放、消耗手牌 |
| Silent | 中毒 / 小刀 / 防御 | 中毒、无实体、小刀+ |
| Defect | 充能球 / 集中 / 栏位 | 集中、黑暗球、栏位 |
| Necrobinder | 灾厄 / 灵魂 / 奥斯提 | 灾厄、灵魂、召唤 |
| Regent | 星 / 无色牌 / 铸造 | 星、升级无色牌、铸造 |

## 三、与其他池的对比

### 3.1 池规模

| 药水池 | 数量 | 说明 |
|--------|------|------|
| `SharedPotionPool` | 45 | 通用（Common ×15 / Uncommon ×15 / Rare ×15），其中 6 瓶由 `Potion1Epoch` / `Potion2Epoch` 锁定 |
| 角色专属池 × 5 | 15 | 每角色 Common ×1 / Uncommon ×1 / Rare ×1 |
| `EventPotionPool` | 2 | FoulPotion、GlowwaterPotion（事件/商人用途） |
| `TokenPotionPool` | 1 | PotionShapedRock（战斗中生成的代币药水） |
| `DeprecatedPotionPool` | 1 | DeprecatedPotion（已移除） |
| `MockPotionPool` | 1 | MockDiscardAndAddShivsPotion（仅测试） |
| **合计独立模型** | **65** | — |

### 3.2 奖励抽取逻辑（`PotionFactory`）

1. `GetPotionOptions` = 角色池已解锁药水 ∪ 共享池已解锁药水。
2. 先按稀有度掷骰：`Rare ≤ 10%`、`Uncommon ≤ 35%`、否则 `Common`（即 10% / 25% / 65%）。
3. 再在**该稀有度的全部候选**（共享 + 专属）中随机取一瓶。
4. 因此，角色每加 1 瓶专属药水，等于在该稀有度档位里多一个候选；专属池本身的 1/1/1 结构不改变稀有度权重，只改变候选分布。

## 四、对贝拉专属药水设计的参考结论

1. **数量**：原版每个角色固定 **3 瓶**专属药水（无初始药水、无 Starter 稀有度）。贝拉对齐目标为 **3 瓶**。
2. **稀有度**：固定 **Common ×1 + Uncommon ×1 + Rare ×1**，不做 Event / Token 稀有度。
3. **解锁**：贝拉 `RequiresEpochAndTimeline = false`，`BellaPotionPool` 目前未覆写 `GetUnlockedPotions`（默认全放行），所以 3 瓶应**开局即可进入奖励池**；若想让某瓶更晚出现，再自行加条件（如心之壁层数、阴阳状态等），不要依赖原版纪元。
4. **主题绑定**：3 瓶最好各自强化一条贝拉特色——建议 1 瓶围绕**阴阳（白拉/黑拉/反差牌）**、1 瓶围绕**心之壁经济**、1 瓶围绕**充能球/第二资源联动**；也可 1 瓶设计成"阴阳二选一"的双面药水（如根据当前白拉/黑拉给出不同效果），这是专属药水最自然的差异化表达。
5. **数值风格**：原版专属药水数值普遍在 1~33 的小数字区间，且通过 `DynamicVar`（`PowerVar` / `CardsVar` / `RepeatVar` / `SummonVar` / `StarsVar` 等）驱动本地化文本；贝拉药水沿用同一套展示体系即可（心之壁公式可继续用 ÷15、1+d÷3 等）。
6. **使用时机**：原版 14/15 为 `CombatOnly`（只有回血药水是 `AnyTime`）。贝拉若做"回复/心之壁类战斗外可用"效果可设为 `AnyTime`，否则保持 `CombatOnly` 更符合原版风格。
7. **实现提示**：RitsuLib 提供 `ModPotionTemplate`（支持 `RegisteredKeywordIds` 悬浮提示展示与 `PotionAssetProfile` 图片/轮廓路径）；注册用 `[RegisterPotion(typeof(BellaPotionPool))]` 或 content pack 的 `.Potion<BellaPotionPool, TPotion>()`；本地化写在 `potions.json` 的 `{ENTRY}.title` / `.description`（可选 `.selectionScreenPrompt`）。
