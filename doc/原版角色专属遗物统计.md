## 一、概念与总体结论

### 1.1 什么是"角色专属遗物"

每个可玩角色拥有一个专属遗物池（`{角色}RelicPool`），池中的遗物**不会**出现在共享遗物池（`SharedRelicPool`）中，因此属于该角色独有内容。

| 角色 | 池文件 | 池内遗物数 | 起始遗物 |
|------|--------|-----------|----------|
| 铁甲战士 Ironclad | `IroncladRelicPool` | 8 | 燃烧之血 |
| 静默猎人 Silent | `SilentRelicPool` | 8 | 蛇之戒指 |
| 机器人 Defect | `DefectRelicPool` | 8 | 破损核心 |
| 死灵法师 Necrobinder | `NecrobinderRelicPool` | 8 | 缚魂命匣 |
| 君王 Regent | `RegentRelicPool` | 8 | 天赋君权 |
| **合计** | — | **40（无重复）** | 5 |

> 五个角色池互不重叠：40 件专属遗物均为唯一 ID。

### 1.2 稀有度构成：完全统一的"8 件套"模板

| 稀有度 | 数量 | 说明 |
|--------|------|------|
| Starter（初始） | 1 | 角色开局携带，**不会**进入奖励/商店（`RelicGrabBag` 只取 Common/Uncommon/Rare/Shop） |
| Common（普通） | 1 | 普通奖励池 |
| Uncommon（罕见） | 2 | 罕见奖励池 |
| Rare（稀有） | 3 | 稀有奖励池 |
| Shop（商店） | 1 | 商店稀有度；不锁纪元，开局即可在商店/奖励中遇到 |
| **合计** | **8** | 1 初始 + 7 可获取 |

### 1.3 解锁（时间线纪元）规律

每个角色池通过 `{Char}3Epoch` 与 `{Char}6Epoch` 各锁定 3 件：

| 解锁状态 | 数量 | 典型构成 |
|----------|------|----------|
| 开局即可获得 | 2 | Starter ×1 + Shop ×1 |
| 纪元 3 解锁 | 3 | 多为 Common/Uncommon + 1 Rare |
| 纪元 6 解锁 | 3 | 多为 Uncommon/Rare |

即：**每角色 7 件可获取遗物中，2 件开局可见，其余 6 件分两批解锁**。

### 1.4 设计主题

角色专属遗物全部围绕该角色核心机制展开：

| 角色 | 核心主题 | 遗物关键词 |
|------|----------|------------|
| Ironclad | 力量 / 自愈 / 烧血 | 力量、易伤、受伤、消耗、生命阈值 |
| Silent | 小刀 / 中毒 / 弃牌 | 小刀、中毒、虚弱、弃牌、抽牌 |
| Defect | 充能球 / 集中 / 能量 | 充能球、集中、栏位、0 费卡 |
| Necrobinder | 亡灵 / 灾厄 / 召唤 | 奥斯提、灾厄、灵魂、虚无、保留 |
| Regent | 星能 / 铸造 / 仆从 | 星星、铸造、仆从、无色牌、生成牌 |

## 三、触发时机分类（设计可复用参考）

按回调/钩子类型归类，供贝拉专属遗物设计时挑选：

| 类型 | 原版示例 | 设计要点 |
|------|----------|----------|
| 战斗开始时一次性 | NinjaScroll、CrackedCore、DataDisk、PowerCell、RunicCapacitor、SymbioticVirus、BigHat、FuneraryMask、BoundPhylactery、DivineRight、FencingManual、OrangeDough | 全部限定第 1 回合（`TurnNumber <= 1`） |
| 每回合开始 | Brimstone、EmotionChip | `AfterSideTurnStart` / `AfterPlayerTurnStart` |
| 每回合结束 | LunarPastry | `AfterSideTurnEnd` |
| 出牌/丢牌/消耗/受击 | CharonsAshes、HelicalDart、Tingsha、ToughBandages、SelfFormingClay、DemonTongue、IvoryTile | `AfterCardPlayed` / `AfterCardExhausted` / `AfterCardDiscarded` / `AfterDamageReceived` |
| 被动数值修改器 | PaperPhrog、PaperKrane、SneckoSkull、GoldPlatedCables、UndyingSigil、VitruvianMinion | `ModifyXxx` 系列，不改事件逻辑 |
| 条件阈值/状态切换 | RedSkull、UndyingSigil、EmotionChip | 持久状态 + 主动/被动切换 |

## 四、对贝拉专属遗物设计的参考结论

1. **数量**：原版每个角色池固定 **8 件** = 1 Starter + 7 非 Starter；非 Starter 中 Common×1、Uncommon×2、Rare×3、Shop×1。
2. **Starter 不进奖励池**：`RelicGrabBag` 的 `_rarities` 只包含 Common/Uncommon/Rare/Shop；所以设计贝拉遗物时，**真正的"可获取专属遗物"目标是 7 件**。
3. **当前贝拉池状态**：`BellaRelicPool` 已注册 `Bellaris` 与 `KiraBellaris` 两件 Starter 型遗物（后者是"奥罗巴斯之触"升级版，永不进奖励）。若按原版"7 件可获取"对齐，需新增：**Common×1、Uncommon×2、Rare×3、Shop×1**（共 7 件；此时池内总数 9，包含升级变体。若严格要求池内总数 8，则把 `KiraBellaris` 视作升级变体不占池位，只需新增 6 件——设计时建议以"7 件可获取"为主要对齐目标）。
4. **解锁节奏**：原版每角色开局可见 2 件（含 Starter），其余 6 件分两批（3 件 + 3 件）随纪元解锁；贝拉已声明不启用纪元/时间线（`RequiresEpochAndTimeline = false`），因此 7 件可获取遗物预计全部放开（或由自身条件解锁，如阴阳状态/心之壁）。
5. **主题绑定**：每件专属遗物都应至少强化一条角色特色——贝拉的核心特色是**阴阳（白拉/黑拉）**、**心之壁**与**充能球**；建议 7 件中：2~3 件围绕阴阳状态（白拉/黑拉差异触发、反差牌、差值 d），2~3 件围绕心之壁经济，1~2 件围绕充能球/第二资源联动。
6. **数值风格**：原版专属遗物数值普遍在 1~10 的小数字区间，且通过 `DynamicVar` 驱动文本；继承此风格可让贝拉遗物的贝极星/心之壁公式（÷15、1+d÷3 等）保持同一套展示体系。
