# Slay the Spire 2 原版角色卡牌统计

> 数据来源：游戏反编译源码 `CardModel` 构造函数中的 `CardType` 和 `CardRarity` 声明。
> 
> 统计日期：2026-07-14

---

## 一、卡牌分类体系

### 卡牌类型 (CardType)

| 类型 | 枚举值 | 说明 |
|------|--------|------|
| 攻击牌 | `Attack` | 造成伤害或攻击类效果 |
| 技能牌 | `Skill` | 防御、过牌、操作类效果 |
| 能力牌 | `Power` | 提供持续增益/状态效果 |
| 状态牌 | `Status` | 战斗中产生的负面卡牌（不可收集） |
| 诅咒牌 | `Curse` | 永久负面卡牌（不可收集） |
| 任务牌 | `Quest` | 任务相关卡牌 |

### 卡牌稀有度 (CardRarity)

| 稀有度 | 枚举值 | 说明 |
|--------|--------|------|
| 基础 | `Basic` | 角色初始卡组自带 |
| 普通 | `Common` | 最常见掉落 |
| 罕见 | `Uncommon` | 中等稀有度 |
| 稀有 | `Rare` | 高强度/特殊机制 |
| 远古 | `Ancient` | 纪元系统解锁（类似旧版 BOSS 遗物卡） |
| 事件 | `Event` | 事件专属卡 |
| 代币 | `Token` | 战斗中生成的临时卡 |

### 5.3 稀有度分布规律

游戏采用了高度标准化的卡池结构：

| 稀有度 | 数量（除 Ironclad 外） | 备注 |
|--------|----------------------|------|
| Basic | 4 | Ironclad 为 3（少 1 张基本技能牌） |
| Common | 20 | 所有角色一致 |
| Uncommon | 36 | 所有角色一致 |
| Rare | 26 | 所有角色一致 |
| Ancient | 2 | 纪元系统解锁，所有角色一致 |

> Ironclad 少 1 张 Basic 卡（87 vs 88），因为其起始卡组为 5 攻 + 4 防 + 1 Bash（共 10 张），没有第二张角色专属起始技能牌。

## 六、其他卡池

### 6.1 无色卡牌 (ColorlessCardPool)

无色卡牌池约 **64** 张，不受角色颜色限制，包括 `HandOfGreed`、`Apotheosis`、`MasterOfStrategy`、`TheBomb` 等通用卡。

### 6.2 非收集卡牌

| 卡池 | 数量 | 说明 |
|------|------|------|
| 诅咒卡 (Curse) | ~18 张 | 如 `AscendersBane`、`Normality`、`Regret` 等 |
| 状态卡 (Status) | ~9 张 | 如 `Burn`、`Dazed`、`Wound`、`Void` 等 |
| 代币卡 (Token) | ~5 张 | 如 `Shiv`、`Soul`、`GiantRock` 等 |
| 任务卡 (Quest) | ~3 张 | 如 `ByrdonisEgg`、`LanternKey`、`SpoilsMap` |

## 七、纪元 (Epoch) 解锁系统

每个角色有 3 个纪元阶段（如 `Ironclad2Epoch`、`Ironclad5Epoch`、`Ironclad7Epoch`），对应角色等级 2/5/7。未达到对应纪元时，纪元内的卡牌不会出现在奖励和商店中。

- 无色卡池有 5 个纪元 (`Colorless1Epoch` ~ `Colorless5Epoch`)
- Ancient 稀有度的卡牌需要通过纪元系统解锁
